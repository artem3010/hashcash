# Hashcash Сервер и Клиент

## Описание

Этот проект реализует сервер и клиент, использующие алгоритм **Hashcash** для Proof of Work (PoW). Клиент
взаимодействует с сервером для получения цитат, а сервер проверяет PoW через middleware. Сервер и клиент спроектированы
для защиты от DoS-атак с помощью PoW, что требует вычислительных усилий для каждого запроса.

## TLDR

Сервер сделан на основе Middleware который проверяет результат подсчета задачи PoW и проверяет токен.
Токен получаем из secretKeyProvider, в данной реализации это просто env переменная.
Токен также содержит IP, чтобы нельзя было атаковать сервер с разных машин, если на одной получили правильный результат
PoW.
У решения задачи есть время жизни которое устанавливается в TOKEN_TTL.

Чтобы запустить клиент и сервер (сервер стартует на 8080, клиент на 8081):

Поверх клиента, для удобства, есть HTTP ручка с путем "/getQuote", который вызывает клиент с POW
Т.е. http://localhost:8081/getQuote вызовет клиента, который обратится к серверу и вычислит PoW Challenge.

```bash
# Собрать образы Docker для сервера и клиента
make build

# Запустить контейнеры для сервера и клиента
make run
```

## Требования

- **Docker**: Используется для создания и запуска контейнеров для сервера и клиента.
- **Go 1.23+**: Требуется для запуска приложения на локальной машине, если вы не хотите использовать Docker.
- **Make**: Makefile предоставляет удобные команды для сборки, запуска и остановки Docker контейнеров.

## Настройка

Для работы с проектом необходимо установить Docker, Docker Compose и Make.

### Сборка и запуск с Docker

Чтобы собрать и запустить контейнеры сервера и клиента отдельно:

```bash
# Собрать образы Docker для сервера и клиента
make build

# Запустить контейнеры для сервера и клиента
make run
```

### Сборка и запуск с Docker Compose

В качестве альтернативы, вы можете использовать Docker Compose для управления сервером и клиентом:

```bash
# Собрать образы с помощью docker-compose
make compose-build

# Запустить сервер и клиент через docker-compose
make compose
```

### Остановка Docker контейнеров

Чтобы остановить и удалить контейнеры:

```bash
make stop
```

### Просмотр логов

Для просмотра логов сервера и клиента:

```bash
make logs
```

### Очистка неиспользуемых Docker ресурсов

Чтобы удалить неиспользуемые Docker образы, контейнеры и тома:

```bash
make clean
```
